## Features:
- Gives Hel mobs a proper summon message
- Outputs exact damage number after defeating a super
- Gives squares a MUCH more visible name
- Increases size of Ready button
- Gives every beetle / variant of a different mob a tag (Ex: pharoah beetle nametag goes from `Beetle` to `Beetle (Phar)`)

## Script usage: (Scripts are not condoned, use at your own risk)
- Install tampermonkey
- Install the userscript (`autolang.user.js`)
(Will allow use without having to reload game every time)

## How to manually load a language pack
- Download the language file (Modified or unmodified)
- Open your browser's developer tools (look up a tutorial if too hard)
- Type in or paste `florrio.utils.uploadCustomLang()`
- Upload the language file (If you are told to upload a set of different language files, it does not matter because the function appends them anyways)
